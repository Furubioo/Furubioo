## Projeto em destaque

### 🎬 Lumière Cinema

<a href="https://github.com/Furubioo/Sistema-de-Cinema-JAVA-">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Furubioo&repo=Sistema-de-Cinema-JAVA-&theme=tokyonight&hide_border=true" alt="Card do repositório Sistema de Cinema" />
</a>

**Lumière Cinema** é um sistema acadêmico de venda/reserva de ingressos desenvolvido em etapas, acompanhando minha evolução de fundamentos de orientação a objetos para uma aplicação web.

| Etapa          | O que foi trabalhado                                                                         |
| -------------- | -------------------------------------------------------------------------------------------- |
| **Console**    | Java, orientação a objetos, herança, interfaces, exceções, persistência e padrões de projeto |
| **Web**        | React + Vite no front-end e Spring Boot no back-end                                          |
| **Dados**      | Banco H2, com persistência local para a aplicação web                                        |
| **Integração** | Comunicação entre front-end e back-end, configuração de ambiente e correção de bugs          |

Na versão web, parte do código foi gerada com apoio de ferramentas de IA. Minha contribuição esteve principalmente na **configuração do ambiente, integração entre as camadas e resolução de problemas de implementação**, incluindo lógica de sugestão de assentos, filtros de cupons e carregamento de pôsteres via TMDB.
