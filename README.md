<h2 align="center">Sobre</h2>

<div align="center">

> **Não estou apenas aprendendo ferramentas. Estou construindo fundamentos.**

</div>

Sou estudante do **4º período de Ciência da Computação na UNICAP**, com formação técnica anterior em **Redes de Computadores**.

Comecei em Sistemas de Informação e migrei para Ciência da Computação em busca de uma base mais sólida: compiladores, estruturas de dados, métodos numéricos e infraestrutura de software. Foi uma escolha por profundidade, não por atalho.

Hoje meus interesses se concentram em **dados, desenvolvimento de software e back-end** — três áreas que, no meu caso, não apareceram por tendência de mercado, mas como consequência direta das disciplinas que venho cursando.

```text
Redes de Computadores  →  Sistemas de Informação  →  Ciência da Computação
      (técnico)                  (transição)              (atual · UNICAP)
```

### Um projeto construído em camadas

O **Lumière Cinema** acompanhou a evolução das disciplinas: começou como um sistema de console em Java puro e terminou como uma aplicação web completa. Cada camada corresponde a um conceito que eu estava estudando na época.

```text
  ┌─ CAMADA 1 ──────────────────────────────────────┐
  │  Java · Console                                 │
  │  Herança · Interfaces · Exceções                │
  │  Sobrescrita · Sobrecarga                       │
  └──────────────────────┬──────────────────────────┘
                         ▼
  ┌─ CAMADA 2 ──────────────────────────────────────┐
  │  Padrões de projeto                             │
  │  MVC · Strategy                                 │
  └──────────────────────┬──────────────────────────┘
                         ▼
  ┌─ CAMADA 3 ──────────────────────────────────────┐
  │  Aplicação web                                  │
  │  React + Vite · Spring Boot · H2 · API TMDB     │
  └─────────────────────────────────────────────────┘
```

**O que resolvi na prática:** lógica de sugestão de assentos, filtros de cupons de desconto, integração entre front-end e back-end, configuração de ambiente e carregamento de pôsteres via API do TMDB.

<sub>Na etapa web, parte do código foi produzida com auxílio de ferramentas de IA. Minha atuação se concentrou em configuração, integração e resolução dos problemas de implementação.</sub>
